# Dynamic User Profile Cards

A simple React project built while learning the fundamentals of React.

## Features

- Reusable Components
- Props
- Rendering Lists with `.map()`
- Dynamic User Cards
- Responsive Card Layout

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS3
- Lucide React

## What I Learned

- Creating reusable components
- Passing data using props
- Rendering UI from an array of objects
- Using `key` while rendering lists
